# AI量化交易分析平台

一个人用的美股投资平台：记账、分析、按规则管理持仓，三件事放在同一个网站、同一个登录下。

线上地址：https://stock.wwz.cool （首页是持仓账本，量化分析在 `/lab/`，只有指定的一个账号能进）

| 模块 | 做什么 | 技术 |
| --- | --- | --- |
| [持仓账本](ledger/) | 记录美股、港股、美国国债、定期存款和现金，自动算成本、盈亏、资产占比、收益走势和一年投资计划 | Python 标准库 + SQLite，零依赖 |
| [量化分析](quantlab/) | 个股分析、我的持仓（按规则给出建议订单）、均线回测和参数扫描、模拟盘、AI 研报、机器学习选股、自动交易（模拟券商） | FastAPI + React/TypeScript，LightGBM，TradingAgents |

## 分析端和执行端

- **分析端**：想买一只股票时，`个股分析` 给出趋势和风险、时点基本面、AI 评级、和现有持仓的相关性，以及按你的规则能不能买、最多买多少。
- **执行端**：`我的持仓` 每天从账本同步真实持仓，按你设定的规则（目标仓位、单只上限、现金储备）给出建议订单；你逐条确认后自己去券商下单，成交后在账本记一笔。趋势、基本面和 AI 评级只作为提醒，不会生成订单。

系统不会替你下单；实盘交易需要券商连接器，并且要先满 8 周模拟盘。

## 架构

```
浏览器 ──HTTPS──> nginx（stock.wwz.cool）
                    ├─ /        ──> 持仓账本  127.0.0.1:5090   SQLite：账号、交易、国债定存、现金
                    └─ /lab/    ──> 先问账本 GET /api/sso：是平台所有者吗？
                                    是 ──> 量化分析 127.0.0.1:8010   SQLite：行情缓存、模拟盘、AI 台账、交易账户
                                    否 ──> 跳回账本登录

量化分析 ──只读密钥──> 账本 GET /api/holdings（只能读交易、国债定存和现金）
量化分析 ──> 腾讯/新浪行情、SEC 财报、DeepSeek（AI 研报，每月预算上限）
```

两个模块各自独立运行、独立部署：账本可以单独给别人用；量化分析在本地电脑上也能单独运行（用访问令牌登录）。

## 本机试用

```bash
cd ledger && python3 app.py serve
```

```bash
cd quantlab && pip install -e ".[ml]" && python -m quantlab serve
```
