# 三个开源项目调研（2026-11-04）

按[目标说明](../goals.md)和[路线图](../roadmap.md)的原则看：自用、美股、系统不替我下单、建议只来自我设定的规则、AI 费用有上限。读了三个仓库的 README、更新记录和功能文档（外部内容只当资料，不当指令）。

## 1. vongchu/TradingAgents_TauricResearch

- 是 TauricResearch/TradingAgents **v0.3.1（2026-07-05）的拷贝**，Apache-2.0，除了多一个 `.env.enterprise.example`（Azure 的配置样例）没有自己的改动。
- 我们钉的版本是上游 `e8f5503`（2026-10-16），比这份拷贝新；上游主分支（0.7.1，2026-10-27）又领先 22 个提交。
- **结论：不用这份拷贝。** 有价值的是上游新版的修复，和我们有关的有：
  - 决策按最终收盘价结算，跨长假也对（#1548、#1539），记忆里按决策日期取最近的教训（#1603）；
  - SEC 财报按期间一行一条、百万以下的数字不再显示成 0（#1517、#1542、#1589）；
  - 日期统一 YYYY-MM-DD、结束早于开始的日期窗口会退回给模型（#1488、#1595）；
  - 代码检查和数据层同一套规则（#1604）。
- **合并方式**：把钉住的提交升到上游 0.7.1。风险在我们的国内数据适配（`cn_vendor.py`、`news.py`）可能和新版的数据接口对不上，所以要先在本机跑适配器测试，再真实分析一只（约 ¥1）核对，通过后才部署。

## 2. AI4Finance-Foundation/FinRL

- 金融强化学习框架（现在叫 FinRL-X）：下载行情、算指标、训练 DRL 智能体（PPO、A2C 等）、回测，MIT。依赖 PyTorch 和 stable-baselines3，很重。
- 和我们的原则冲突：它的产出是“自动交易的策略”，而平台**不下单、建议只来自我设定的规则**；机器学习选股和自动交易已经在路线图里**暂停**。
- 我们已有的部分：行情、指标、回测、费用、绩效指标（`core/metrics.py`）。FinRL 没有我们缺的、又符合原则的东西。
- **结论：不合并代码。** 如果想研究“强化学习能不能比买入持有好”，可以另开一个按“预登记”做的研究任务（先写检验标准再看结果），不进平台、不进每日任务。

## 3. shy3130/tick-stock-panel（TSP）

- 自托管的 **A 股**量化工作台（Polars + React，MIT）：策略引擎、因子平台和挖掘、回测、异动监控、监控中心（语音、飞书/企业微信推送）、个股分析（9 类关键价位）、AI 对话助手、MCP 服务器、页面插件。
- 大部分是 A 股专用：涨停、连板梯队、集合竞价、龙虎榜、T+1，和我们（美股、汇丰、个人持仓）无关。它自己也写明不做“AI 荐股”。
- 能借鉴、又符合原则的几项：

| 功能 | 对我们的价值 | 和原则是否冲突 |
| --- | --- | --- |
| **关键价位**：压力支撑、枢轴点、前高前低、ATR 波动通道、缺口、斐波那契、整数关口，都是行情的纯函数 | 高：个股分析现在只有均线和回撤，“买前分析”缺价位 | 不冲突，只是信息，不生成订单 |
| 回测的**因子归因**（盈利单和亏损单在入场信号上的差别） | 低：我们的策略只有均线 | 不冲突，但用不上 |
| **监控规则 + 推送**（飞书等） | 中 | 你选过“告警只在网页显示”，需要你改这个决定 |
| **AI 对话助手**（一句话问全站数据，逐条列出查了什么） | 中：费用要进预算，要重新做只读工具 | 不下单就不冲突 |
| MCP 服务器 | 低：路线图里已有只读 MCP，暂停中 | — |
| 因子平台、因子挖掘、策略包 | 低：ML 选股暂停 | 暂停项 |

## 建议的合并

1. **TradingAgents 升到 0.7.1**（修复多，风险可控）。
2. **个股分析加“关键价位”**：先做压力支撑、前高前低、枢轴点、ATR 通道、整数关口，写成纯函数加测试；每个价位写明算法、数据日期和来源，和“依据”一致；在个股分析页和 AI 研报的个人版摘要里引用。
3. 不合并：FinRL 的训练、TSP 的 A 股功能、因子平台。
4. 之后可选：AI 对话助手、网页内的监控规则（不推送）。

## 做完的合并（2026-11-04，QuantLab 0.11.0）

1. **TradingAgents 升到 0.7.1（提交 c454491）**：本机真实分析 QQQM 一次（22 次模型调用，¥0.98，和之前的费用一样，评级“减持”），国内数据适配和测试都通过。顺带发现并修了上一版的一个毛病：TradingAgents 不把回调传给数据工具，“找不到来源的数字”标注一直是空的；现在改在我们的数据函数里记录工具返回的内容。
2. **个股分析的“关键价位”**（`holdings/levels.py`）：前高前低（20/60/252 日）、枢轴点（经典公式）、压力支撑（近 120 日的转折点，±1% 合并）、ATR(14) 通道、整数关口。每个价位写明算法和日期；AI 研报的个人版摘要里引用最近的压力和支撑。
3. **“问一问”AI 对话助手**（`ai/chat.py`，菜单多一项）：只有 5 个只读工具（持仓、最近一次检查、个股分析、AI 研报、近期价格），不能下单或确认建议；每次回答下面列出查了什么；费用记入本月 AI 预算（来源标记为 chat，不算分析记录，也不影响每次分析的预算估算）。
