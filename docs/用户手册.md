# AI量化交易分析平台 · 使用手册

适用版本：账本 2026-11 版、量化分析 0.12.x。网址：**https://wwz.hk.cn**（量化分析在 **/lab/**）。

---

## 一、这是什么

一个**只给自己用**的美股投资平台，把三件事放在同一个网站、同一个登录下：

| 做什么 | 在哪里 | 一句话 |
| --- | --- | --- |
| **记账** | 持仓账本（首页 `/`） | 把美股、港股、美国国债、定期存款记在一处，自动算成本、盈亏、占比、收益走势 |
| **管理持仓** | 量化分析 → 我的持仓 | 你先定规则（目标占比、单只上限、现金储备），系统每天按规则检查，**只提建议，不下单** |
| **买前分析和研究** | 量化分析 → 个股分析、AI 研报、问一问、均线回测 | 趋势、关键价位、基本面、AI 研报、和现有持仓的关系，以及你的规则允许买多少 |

### 四条不会变的原则

1. **系统不替你下单。** 不接任何券商的下单接口。建议订单上的“确认”只是记录你同意，下单要你自己在汇丰 App 里做，再回账本记一笔。
2. **建议只来自你设定的规则。** 趋势、价位、基本面、AI 评级、均线信号都只是**提醒和参考**，不会变成订单。
3. **只有你能用。** 量化分析只对账本里的指定账号开放。
4. **AI 有预算上限。** 每月 ¥100，排队时和运行前各检查一次。

> 本平台的一切内容仅供研究，**不构成投资建议**。AI 生成的内容可能有事实错误，用之前请核对。

## 二、第一次使用：5 步

1. 打开 **https://wwz.hk.cn**，用你的账号登录（用户名 `admin`）。忘记密码见“十一、常见问题”。
2. 在账本首页点 **＋ 记一笔**，把已有的买卖、国债、定存、现金录进去（或用“导入”批量录）。
3. 点 **↻ 刷新数据**，取最新价格、收盘价和汇率，几秒完成。
4. 点左上角导航里的 **量化分析**（首页“更多 ▾”里，或直接访问 `/lab/`），进入 **持仓规则** 页，设置目标占比和上限。
5. 回到 **总览**，看“持仓检查”：有没有建议订单、有哪些提醒。

之后日常基本不用做什么：系统每天自动检查，你只看总览。

## 三、系统每天自动做什么

| 时间（北京时间） | 谁做 | 做什么 |
| --- | --- | --- |
| 开市时每 30 秒 | 账本 | 自动更新持仓里正在交易的股票的现价（标“盘中”），收盘后补一次改成“收盘” |
| 03:30 | 账本 | 数据库本地备份，保留 30 份 |
| 06:15 | 账本 | 自检所有行情接口（腾讯、新浪、东方财富），结果显示在“系统状态” |
| 周二至周六 09:00 后 | 量化分析 | **每日任务**：先确认腾讯已有美股最近一个收盘日的数据（没有就每半小时再查，最晚等到 12:00）→ 同步账本 → **持仓检查**（按规则出建议订单和提醒、核对收盘价）→ 记录模拟账户当天的决定（AI 自动分析已关闭，不再花钱） |
| 账本有新交易时（每 3 分钟看一次） | 量化分析 | 自动同步账本并重新检查持仓 |
| 每天 9:30 和每次登录电脑时 | 你的电脑 | 计划任务 `LedgerBackupPull`：让服务器做一份最新备份，拉到 `Desktop\stock-projects\ledger-backups`（保留 60 份） |

美股周一到周五开市，北京时间对应周二到周六的凌晨收盘，所以每日任务是周二到周六。

## 四、持仓账本（首页）

### 4.1 页面从上到下

- **我的股票组合**（最上面一张卡）：把你持有的所有股票合成**一个标的**，像看一只股票那样看它：大字是这些股票合计的现值（它的“价格”），旁边是较上一收盘的涨跌额和涨跌幅，右上角标“盘中 · 自动更新”或“x/x 收盘”，下面写更新时间。开盘时数字会自己跳。只算股票，不含国债、定存和现金；港股按当前汇率折成美元；没有价格的股票不计入并会提示。
  - **分时线**：卡片里有一张分时线图，横轴是这一场的交易时间（北京时间，美股约 22:30 到次日 05:00，冬令时），纵轴以上一收盘（虚线）为中线上下展开，线在虚线上方是涨、下方是跌。默认画整个组合；上面的小按钮可以切到单只股票。鼠标移到线上（手机上手指按住滑动）会显示那一分钟的时间、数值和涨跌。开盘时每半分钟左右更新一次，休市时显示最近一场。数据来自腾讯财经的分钟线，只取你持有的股票。
- **资产占比**：环形图 + 明细，按总资产（股票 + 国债 + 定存 + 现金）算。顶部有“现资产 / 原始资产 / 盈亏”。
- **股票**：每只股票占全部股票现值的比例，和股票部分自己的盈亏（浮动 + 已实现）。表格里每只持仓的股数、平均成本、现价（标“盘中”或“x/x 收盘”）、当日涨跌、浮动盈亏。
- **收益走势**：每天的累计收益和收益率曲线，标出买卖点、拆合股、最高、最低、最大回撤；“收益构成”把累计收益分成股价涨跌、国债和定存利息，相加等于总收益。
- **一年投资计划**：从第一笔投资起算一年，显示还剩多少天，月历里每天的盈亏，点格子看当天明细。
- **国债和定期存款**：每笔的本金、到期日、收益率、已计收益、含应计利息的现值。
- **现金**：账户里还没投资的钱。计入资产占比和总资产，不计入收益率。
- **交易记录**：按方向（买入、卖出、拆合股）和代码筛选，按月分组小计。
- **系统状态**（只有你能看，**只在出问题时显示**）：本地备份、异地备份、恢复演练、行情接口、运行版本，超时或失败标 ⚠。
- 右上角“**更多 ▾**”：股票看板（K 线、金价）、读书清单、账号。

### 4.2 记一笔

点 **＋ 记一笔**，一个弹窗里可以录：

| 类型 | 要填什么 |
| --- | --- |
| 股票买卖 | 代码（支持中文名、英文名搜索）、买/卖、日期、股数、价格、费用、备注（比如汇丰指示号） |
| 拆股、合股 | 生效日、比例（1 拆 2、10 合 1）。从那天起股数按比例调整、总成本不变，收益走势不会出现断崖 |
| 美国国债 | 名称、面值、成交净价、票息、结算日、到期日 |
| 定期存款 | 本金、年利率、存入日、到期日 |
| 现金 | 币种、金额 |

要点：
- 默认以美元记账，港股成交按港元记、汇总时折成美元。
- 成本按**移动平均法**算；卖出的已实现盈亏计入总收益。
- 国债**按持有到期**算：票息按天累计，买入价和面值的差额平摊到到期日，买入时付的应计利息会扣掉。也可以在“参考卖出价”里填券商 App 上的卖出参考价（%），从那天起按市价算；清空就恢复持有到期。
- 定存利息按天平摊；到期后本息回到储蓄账户，不再计入国债定存（记得在账本里更新现金）。

### 4.3 批量导入

**交易记录**区右侧有“导入”：粘贴 Excel / CSV 表格，或导入“账号”页导出的文件；也支持上传券商成交截图自动识别（需要先开通识别服务）。识别和导入的结果都先给你核对，再保存。

### 4.4 刷新数据和价格

- **自动**：开市时服务器每 30 秒更新现价，打开着的页面每 15 秒读一次，所以价格会自己变，不用点刷新。
- **新买的股票会自动取价格**：在“记一笔”里保存一只还没有价格的新股票（或批量导入）后，页面会立刻自动刷新；服务器也每 30 秒检查一次，持仓里有股票还没有价格或历史行情就自动去取（同一只最多试 3 次，隔 5 分钟，取不到的代码不会一直占着服务器）。不用再点“刷新数据”。
- **↻ 刷新数据**（手动，两次之间要隔 30 秒）：除了现价，还会更新收盘价、历史行情、汇率、金价、拆合股记录和价格核对。新加的股票要点一次才有价格。
- 价格来源：腾讯财经为主，新浪财经核对，东方财富备用。可能有几分钟延迟。
- 你手动改过价格的话，自动更新不会盖掉它（手动的日期更晚时保留）。

### 4.5 价格核对和漏记提示

- **价格核对**：每次刷新都拿第二个来源逐日核对最近 5 个交易日的收盘价，偏差超过 0.2%、缺数据、或数据过期都会在持仓表下方列出，并写明是哪只、差多少。页面上“收盘价已和新浪财经逐日核对：6 只股票最近 5 个交易日一致”就是通过。
- **漏记提示**：刷新时取持仓美股的拆股、合股记录，和你的交易记录对照，可能漏记的会列出，点“记一笔”会预填，核对后保存。

### 4.6 股票看板

“更多 ▾ → 打开股票看板”：每只持仓的日 K 线（均线、成本线、买卖点），按拆股调整，所以拆股前后连续、52 周高低点正确；还有金价和美元兑人民币。

### 4.7 账号

“更多 ▾ → 账号”：改密码、**导出全部记录**、注销账号（会同时删除全部记录，慎用）。

## 五、量化分析（/lab/）

左侧导航共 6 项：**总览、我的持仓、持仓规则、个股分析、AI 研报、问一问**，最下面“← 持仓账本”回首页。手机上导航会折成一行。均线回测等已移出菜单，见 5.6。

### 5.1 总览：每天先看这里

- **持仓检查**：最近一次检查的时间、所用收盘日、有没有**建议订单**、有哪些**提醒**（只是信号，不生成订单）。总览只放这一项，别的都收起来了，打开就是今天要关注的事。

**账本有新交易会自动同步到量化分析**（2026-11-09 起）：量化分析每 3 分钟看一次账本，只有交易、现金或国债定存**发生了变化**（比如新增一笔买入）才会同步并立刻重新检查持仓，几分钟内总览、我的持仓、问一问、AI 研报用的持仓就是最新的，不用再点“同步账本并检查”，也不用等第二天的每日任务。

### 5.2 我的持仓

1. **建议订单**：规则检查后算出的调整，每条写明方向、股数、约价、约金额、**原因**，点“依据”展开：规则、用到的数值、数据日期和来源、计算过程。
   - **确认**：只是记录你同意这笔调整，**系统不会下单**。同意的话，你自己在汇丰下单，成交后到账本“记一笔”。
   - **拒绝**：记录你不同意。每次新检查会让上一次没处理的建议作废。
2. **持仓**：股数、成本、现价、市值、盈亏、占比、目标占比。
3. **提醒**：只是信号，包括现金低于储备、比成本亏太多、距一年高点回撤太深、50 日线在 200 日线下方、最近 AI 评级、财报基本面、国债定存到期、价格核对不一致。每条都能展开“依据”。
4. **国债和定期存款**：用和账本同一套算法估值，所以两边数字一致。
5. **你的规则**：已搬到单独的 **持仓规则** 页（左侧导航，见 5.2.1），规则含义如下（修改后下次检查生效）：

| 规则 | 含义 | 默认 |
| --- | --- | --- |
| 目标仓位 | 例如 `QQQM:40, VOO:30`，可不填 | 无 |
| 再平衡区间 | 偏离目标超过这么多（绝对值）才建议调整 | 5% |
| 单只上限 | 个股占可投资资金（股票 + 现金）的上限，**固定 25%，不能改**；宽基 ETF 可设“不设上限” | 25% |
| 现金储备 | 现金占比下限 | 10% |
| 最小下单金额 | 小于这个的调整不建议 | $50 |
| 按整股 | 买入向下取整，卖出取最接近规则的整股数 | 是 |
| 亏损提醒线 | 比平均成本低这么多就提醒 | 20% |
| 回撤提醒线 | 比一年内最高点低这么多就提醒 | 25% |
| 止盈 | 个股涨到平均成本的 +50% 卖当时股数的 33%，+100% 再卖 33%；每档每次买入一次；可关闭 | 开 |

#### 5.2.1 持仓规则页

左侧导航“持仓规则”（地址 `/lab/rules`），只有两块：

1. **异常与冲突**：最近一次检查发现的所有问题，按严重程度分三类，没有问题就写“没有异常”。
   - **违反规则**（红）：个股超过 25% 上限、现金低于储备、设了目标的股票偏离超出区间、规则之间互相矛盾（目标高于上限、目标合计加现金储备超过 100%）。能生成订单的会写出建议买卖多少股。
   - **需要留意**（黄）：到了止盈档、两个行情来源对不上、取不到行情、国债定存到期、比成本亏太多或离一年高点太远、规则要求调整但价格或现金做不到。
   - **信号提醒**（灰）：AI 评级偏谨慎、财报偏弱，以及已过止盈线但这次没有订单的持仓。
   - 每项能展开“依据”。订单本身到“我的持仓”确认或拒绝。
2. **规则设置**：
   - **固定规则**：单只上限 **25%**，写死，不能改；宽基 ETF（“不设上限的代码”）例外。
   - **止盈**：分两档，只对个股，宽基 ETF 不止盈。默认涨到平均成本的 +50% 卖当时股数的 33%，涨到 +100% 再卖 33%（例：10 股、成本 $100，$150 卖 3 股，$200 再卖 2 股，剩 5 股）。每一档每次买入只提议一次，再买入这只股票后重新计；可以整个关掉。
   - **仓位和现金**：目标仓位、再平衡区间、不设上限的代码、现金储备、最小下单金额、按整股。
   - **提醒线**：低于成本、离一年高点（只提醒，不生成订单）。
   - 保存后点“我的持仓”的“同步账本并检查”，异常就按新规则重算。

### 5.3 个股分析：买之前先看这一页

输入代码（如 `NVDA`），可选填“打算买多少（$）”，点“分析”：

1. 最上面是**结论**：“按你的规则：可以买入，最多约 $X”或“现在不能买入（见下面未通过的规则）”，并逐条列出单只上限、现金储备、整股的检查结果（✓/✗）。**这个结论只来自你的规则**。
2. **关键价位**：前高前低（20/60/252 日）、枢轴点、压力支撑（近 120 日的转折价位）、ATR(14) 通道、整数关口。每个价位写明算法和日期，只是参考，不生成订单。
3. **均线规则**：9 条常见的均线“口诀”（5/10、10/20、20/60、50/200 金叉死叉，站上 20/60/200 日线，多头排列，葛兰威尔买入法则）现在各处于什么状态、从哪天开始，每条后面写着**历史检验的结果**。这一栏只是描述走势，**不是买卖建议**，也不会生成建议订单。检验结论见下面“均线规则靠不靠谱”。
4. **趋势和风险**：1 个月、1 年涨跌、12-1 月动量、年化波动率、相对 QQQ 的 β、距一年高点、最大回撤、50/200 日线。
5. **基本面**（SEC 财报，按公告日取数，不用未来数据）：12 个月收入、净利润、利润率、市盈率等。ETF 没有公司财报会写明。
6. **和你现有持仓的关系**：相关系数、加仓后占比。
7. **参考信号**：最近一次 AI 评级、机器学习排名等。**不构成建议**。

#### 均线规则靠不靠谱

我们把这 9 条规则用 12 只美股（SPY、QQQ、VOO、AAPL、MSFT、NVDA、KO、JNJ、PEP、MCD、ORCL、NIO）、2008 年以来的数据、按汇丰 Trade25 收费逐条检验过（先写好标准再跑，详见 `docs/research/2026-11-ma-rules.md`）：

- **没有一条规则在风险调整后胜过买入持有**，所以它们**不能当作可靠的买卖时机信号**。
- **短周期的最差**（5/10 金叉、站上 20 日线）：每年买卖十几次，来回被小反复打脸，加上每笔 $18 的费用，中位数年化只有约 1%，买入持有是 12%。
- **长周期的好一些，但仍然不如买入持有**：站上 200 日线、50/200 金叉的年化约 8% 到 9%，换来的是更小的最大回撤（宽基 ETF 上从 −35% 降到 −20% 左右），不是更高的收益。
- 在**个股**上同样的规则更差，因为个股的大涨集中在少数几段，规则一空仓就错过。

所以这一栏适合用来**看清走势**（现在在 200 日线上方还是下方、有没有死叉），不适合当成“跌破就卖、站上就买”的操作规则。要不要卖出或减持，由你按自己的规则和判断决定。

### 5.4 AI 研报

用 TradingAgents 的多智能体（技术、情绪、新闻、基本面分析师 → 多空辩论 → 交易员 → 风控与投资组合经理）分析一只股票，给出 **5 档评级（买入、增持、持有、减持、卖出）**和完整报告。

- **新建分析**：输入代码，点“开始分析”，通常几分钟，**约 ¥1**。只分析最近一个收盘日，不回溯历史（避免模型“偷看未来”）；同一只股票同一个收盘日只分析一次。
- **报告页**（点记录编号）：最前面是 **个人版摘要**（评级、**你的持仓情况**、理由、收盘价和 50/200 日线、近一年区间、最近压力和支撑），接着是“**分析时交给 AI 的持仓信息**”（原文），然后是各分析师和最终决定的完整报告。
- **AI 知道你的持仓**（2026-11-05 起）：分析前系统会把你账本里的真实持仓（有没有这只股票、几股、平均成本、占可投资资金多少）、现金、你的持仓规则（单只上限、现金储备、目标占比、整股、最小下单金额）和“只能在券商手动下单、美股和 ETF、不用期权、不做空”的事实交给 AI，并要求它的仓位说法落在这些规则之内、和规则冲突时明说。你没持有的股票，“减持”“卖出”只会被理解成“不买”。账本读不到时，报告会明说“这次没有持仓信息”，不会假装你是空仓。有股票没取到价格时也会写明，占比会偏高。
- 摘要里的“你的持仓”和“最多还能买入”是按你的规则**算出来的**，AI 报告里的仓位建议只是参考，最终以你的规则为准。报告里**数据里找不到的数字**会在该节末尾标出，可能是模型自己推算的，用之前自己核对。报告里期权、领口等按机构写的建议不适用于个人持仓。
- **预算**：本月已用、排队中预计、剩余可用。超过预算的分析不会被提交也不会被运行。
- **每日任务**：显示上次运行时间；“立即运行一次”可以手动跑。
- **AI 自动分析已关闭**（2026-11-04）：之前每 5 天为 AI 模拟账户分析 QQQM、VOO，评级几乎全是“减持”、模拟账户一直没买入，所以停了，现在**只在你手动提交时才分析、才花钱**。要恢复，给量化分析服务设环境变量 `QUANTLAB_AI_AUTO_ANALYSIS=true`。

### 5.5 问一问（AI 对话助手）

用大白话问你的持仓、最近一次检查、某只股票或 AI 研报，例如：

- “我现在的持仓占比是多少？”
- “最近一次持仓检查有什么建议和提醒？依据是什么？”
- “VOO 现在的关键价位在哪里？”
- “QQQM 最近的 AI 评级怎么说？”

特点：
- 助手只有 6 个**只读**工具（持仓、最近一次检查、个股分析、AI 研报、近期价格、均线规则），**不能下单，也不能确认或拒绝建议**。
- 回答下面点“查了 N 项数据”可以看它调用了什么、拿到了什么，方便核对。
- 每次提问约 ¥0.01 到 0.1，计入本月 AI 预算。
- 对话只保存在当前页面里，刷新或点“清空对话”就没了。
- 它只依据工具查到的数据回答，没有的会说“没有这项数据”。回答仍可能有错，重要数字请到对应页面核对。

### 5.6 不在菜单里的页面

精简后下面这些不在菜单里，代码都保留，需要时直接在地址栏打开：`/lab/backtest`（均线回测）、`/lab/scan`（参数扫描 + 样本外检验）、`/lab/paper`（模拟盘）、`/lab/ml`（机器学习选股）、`/lab/trading`（自动交易）。**均线回测**（`/lab/backtest`）：检验“50 日线上穿 200 日线买入、下穿卖出”这类策略在历史上的表现。填代码、均线天数、日期、初始资金、滑点；费用按汇丰收费算（Trade25 默认、标准收费、固定每笔），结果给扣费前后的年化、最大回撤、夏普、权益曲线和交易明细。

## 六、典型使用流程

**买入前**
1. 个股分析输入代码 → 先看结论是否“可以买入”和最多多少。
2. 看关键价位、趋势、基本面；需要时在 AI 研报里新建分析，或在“问一问”里问。
3. 决定后，自己在汇丰下单。
4. 成交后回账本 **记一笔**（成交价、股数、费用、汇丰指示号）。

**每个交易日收盘后（北京时间早上）**
1. 打开量化分析**总览**，看持仓检查：有没有建议订单、哪些提醒。
2. 有建议订单：到“我的持仓”看“依据”，同意就自己下单后记账、点“确认”；不同意点“拒绝”。
3. 提醒只当信号看，不用逐条处理。

**每周**
- 看一眼账本“系统状态”有没有 ⚠。
- 确认电脑上 `ledger-backups` 里有最近的备份文件。
- 看 AI 研报页本月预算用了多少。

**调整规则**：我的持仓 →“你的规则”改完保存，下一次检查生效。

## 十一、常见问题

**忘记密码**：在你自己的电脑终端运行下面的命令，会打印一次性重置码（24 小时有效），在登录页“忘记密码”里输入并设新密码。重置码只会出现在你的终端里。
```bash
ssh wwz 'sudo -u stockledger python3 /opt/stock-ledger/app.py reset-password admin'
```

**价格没更新**：开市时看“盘中”标记；休市时显示最近收盘价。点“↻ 刷新数据”强制更新；系统状态里“行情接口”有 ⚠ 说明某个数据源不通，换源会自动做。

**总览说按某天收盘价，不是今天**：每日任务周二到周六 09:00 后跑，会等腾讯更新收盘数据；收盘价日期写在检查标题里。

**建议订单点了“确认”为什么没下单**：系统从不下单，“确认”只是记录。要下单请自己在汇丰操作，再回账本记一笔。

**AI 研报报“预算不够”**：本月 ¥100 用完了，下个月自动恢复。

**AI 研报里的数字被标了“找不到来源”**：说明这个数字不在这次分析取到的数据里，可能是模型自己算的（比如赔率），也可能写错，用之前自己核对。

**手机上表格要左右滑**：表格在自己的卡片里横向滚动，不会撑破页面；手机上已隐藏次要列。

**证书到期**：网站证书（腾讯云免费，90 天）下一次到期 2027-02-02，到期前要重新申请，已设 2027-01-25 的提醒。

**想看更多信息**：运维手册 `ledger/deploy/OPERATIONS.md`、目标说明 `docs/goals.md`、路线图和决策记录 `docs/roadmap.md`、架构 `quantlab/docs/architecture.md`。

## 十三、术语表

- **收盘价 / 盘中价**：当天最后成交价 / 开市时的最新成交价。
- **平均成本（移动平均法）**：每次买入后重新算平均，卖出按当时平均成本结转。
- **再平衡区间**：持仓偏离目标超过这个幅度才建议调整，避免来回小调。
- **整股**：只买卖整数股，不买零碎股。
- **金叉 / 死叉**：短期均线上穿 / 下穿长期均线。
- **ATR**：平均真实波幅，衡量近期每天的波动幅度。
- **枢轴点**：用前一天最高、最低、收盘算出的参考价位。
- **回撤**：从高点往下跌了多少。
- **SUE**：本季盈利相对去年同期的“意外程度”，明显为负是基本面警示。
- **TradingAgents**：AI 研报用的开源多智能体研究框架。
- **ICP 备案**：国内网站必须的备案，wwz.hk.cn 已通过。
