# 目标说明

确定于 2026-10-21。所有工作都按这一页来排；和它不符的事不做。

## 定位

**AI量化交易分析平台：一个我自己用的美股投资平台，质量对标成熟金融公司的产品。**

## 只做三件事，并把它们做到可靠

1. **记账准确**：每笔交易、持仓、成本、盈亏都对得上，可以和券商（汇丰）对账。
2. **买前分析**：想买一只股票时，看清趋势风险、基本面、AI 研报、和现有持仓的关系，以及按我的规则最多能买多少。
3. **按规则管理持仓**：每天按我定的规则检查持仓，给出建议，我确认后自己下单；信号只作提醒。

## “对标金融公司”的具体含义

| 方面 | 要求 |
| --- | --- |
| 数据正确 | 行情多源交叉校验，异常自动发现；每个数字都能追溯来源 |
| 稳定可靠 | 有监控和告警；每天备份，并且实际演练过恢复 |
| 安全 | 只有我能访问；密钥不出现在代码、日志和聊天里 |
| 可解释 | 每个建议都说清楚依据哪条规则、用了哪些数据 |
| 体验 | 手机上能用，打开一屏就能看清今天该关注什么 |
| 工程规范 | 改动有测试、有 CI、有版本记录，上线前验证 |

## 明确不做

自动实盘下单、多人使用、社区、和大厂比拼 AI 选股。

## 节奏

慢慢来，注重品质。一次只做一件，做完按验收标准检查，再开始下一件。下一件做什么由我决定，不自动往前推。
