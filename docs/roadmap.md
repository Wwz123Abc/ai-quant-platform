# 路线图

按[目标说明](goals.md)排序：自用，质量对标成熟金融公司的产品，慢慢来。一次只做一件，做完按验收标准检查，再由我决定下一件。

## 不变的原则

- **系统不替我下单。** 建议只来自我设定的规则；趋势、基本面、AI 评级只作提醒。不接任何券商的下单接口。
- **只有我能用。** 量化分析只对指定的账本账号开放。
- **AI 费用有上限。** 每月 100 元以内，排队时和运行前各检查一次预算。
- **密钥不出现在代码、日志和聊天里。** 由本人在终端输入（输入时不显示），系统只检查“是否已配置”。
- **研究结论按预登记。** 先写下检验标准再看结果，不通过就如实记录。
